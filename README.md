# atmega32u4-rust-template
This is a template project to get going with the atmega32u4 in Rust.

This template is a result from tedious debugging regarding linker issues, missing symbols in the output .elf file and compilation issues. Hope it gets you going faster, than it did me.

If already here and you came with another AVR MCU in mind check out [Rahix's avr-device](https://github.com/Rahix/avr-device).
